# 任务四  医学影像分割（眼底血管分割）

Kaggle 竞赛 `2026task-4` 的完整实现。输入彩色眼底图，输出同尺寸血管掩膜，提交 run-length 编码，评分 Dice。

Kaggle 最终成绩：**私有榜 0.85980，公开榜 0.85897**。最终提交文件为 `submission.csv`，由种子 2026 的五折模型在阈值 0.40 下直接输出（不是多版本融合），属性见文末。


不联网、不下载预训练权重即可复现 0.85852。`scikit-image` 用于第四通道的 Frangi 响应，缺失时该通道以零填充并在日志里提示。

## 复现命令

数据放在任意目录，用 `--data` 指向它（默认自动查找 `/kaggle/input`）。六步依次执行，`--out` 保持同一个目录：

```bash
cd src

python step1_eda.py  --data /path/to/2026task-4 --out outputs
python step2_train_unet.py --data /path/to/2026task-4 --out outputs \
       --folds 6 --epochs 130 --iters 80 --patch 288 --base 32 --minutes 170 --seed 42
python step3_tta_predict.py --out outputs --patch 288 --base 32 --scales 1.0,1.25,1.5
python step4_tune_threshold.py --out outputs
python step5_ensemble.py --members outputs --out outputs
python step6_submit.py  --data /path/to/2026task-4 --out outputs --csv submission.csv
```

`step5` 的 `--members` 可以给多个目录：先把 `outputs` 拷成 `runA`、`runB`…（各自来自一次不同种子或不同骨干的训练），
再 `--members runA runB runC` 即得到多版本等权融合。四份融合在阈值 0.40 下是 0.85852；榜单最高的一份不是融合结果，复现它只需要单次训练：`--seed 2026` 跑 step2，step4 之后 `step6 --thr 0.40`，不经过 step5。

`step2` 的 `--minutes` 是训练时间预算，程序先测 5 步速度再反推每折轮数，并在每折结束后用真实耗时重新分配，
显存或算力不足时自动少跑轮数而不是中途被杀。

## 关键实现说明

**四通道输入**：绿通道 CLAHE（clipLimit 2.0，网格 8×8）、红通道、蓝通道、绿通道 Frangi 响应（σ 1~4，99.5 分位归一）。

**网络**：四级下采样的残差 U-Net，通道 32/64/128/256/512，解码器双线性上采样 + 跳连拼接，1×1 卷积输出 logit，8.29M 参数。

**损失**：`0.5·BCE + 0.5·Dice + 0.2·clDice`，BCE 与 Dice 都在视野掩膜内统计，clDice 用可微软骨架（3 次迭代）。

**增广**：图块采样 55% 以血管像素为中心；旋转 ±180°、缩放 0.85~1.20、翻转、亮度/gamma/噪声/模糊。

**推理**：整图推理（补边到 16 的倍数），3 个尺度 × 8 个方向（4 翻转 × 2 姿态）取平均，再跨 K 个折模型平均。

**阈值**：不写死 0.5，在交叉验证概率上对「阈值 × 最小连通块」做 45 组网格搜索。多模型融合之后概率分布变窄，
最优阈值会从 0.45 下移到 0.40，因此 `step5` 会在融合后的概率上重新搜一次（这一步单独带来约 0.0007）。

**提交编码**：RLE 为行优先、1-based、每段写「起点 长度」。官方 `segmentation_to_csv.py` 把 PNG 中取值 255 的区域
当作掩膜，所以写 PNG 时血管必须是白色。`step6` 会把自己产出的 CSV 反解码回掩膜与预测逐像素比对，不一致就自动
按相反极性重出一次，两种极性都对不上时才报错退出。

## 已知结果与阴性结论

| 配置 | 线上 Dice |
|---|---|
| v1 基础（5 折 / 90 轮 / 图块 256 / 2 尺度 4 翻转） | 0.85499 |
| v2 加量（6 折 / 130 轮 / 图块 288 / 3 尺度 8 翻转 / SWA） | 0.85631 |
| 修正提交图极性 | 0.85654 |
| 四份概率融合（阈值 0.45） | 0.85780 |
| resnet34 预训练编码器（单模型） | 0.85818 |
| 四份融合 + 阈值 0.40 | 0.85852 |
| **种子 2026 五折集成 + 阈值 0.40（最终提交）** | **0.85897 / 0.85980** |

试过但没有收益的方向，复现时不必重复：伪标签自训练（0.85595）、efficientnet-b3 预训练（0.85542，单步耗时翻倍导致轮数被压）、
按交叉验证质量加权融合（0.85826，验证集排名与榜面排名不一致）、滑窗推理（与整图推理平均绝对差 5e-5，全卷积结构下等价）。

交叉验证 Dice 稳定在 0.8164~0.8168，同配置重跑四次的标准差约 0.0004；而 20 张测试图上的榜面分数在 0.8565~0.8585 之间波动，
名次差 0.0005 以内的比较不具备统计意义。
