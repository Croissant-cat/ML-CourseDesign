东北大学《机器学习》课程设计，四个 Kaggle 任务各占一章。本仓库只放代码与提交文件，报告单独提交。

## 目录

```
ML-CourseDesign/
├── 任务一_植物分类/              任务一：植物分类
├── 任务二_图像情感分类/          任务二：图像情感分类
├── 任务三_中心凹检测定位/        任务三：中心凹检测定位
├── 任务四_医学影像分割/          任务四：医学影像分割
```

每个任务目录下是 `src/step1 … stepN` 的脚本、`README.md`（环境、运行顺序、实验结论）、
`requirements.txt`、`.gitignore` 与最终提交文件 `submission.csv`。

## 复现

四个任务都在 Kaggle Notebook 上运行，GPU 为 T4。各任务的依赖写在对应目录的
`requirements.txt`，运行顺序写在对应目录的 `README.md` 的「复现」一节。
比赛数据与训练权重体积较大，未纳入版本管理，数据从 Kaggle 比赛页下载后挂载到
`/kaggle/input`，权重由训练脚本重新生成。

四个目录下的 `submission.csv` 都是各任务在榜单上取得上述成绩时使用的原始文件。
各 `README.md` 中的指标均来自实际运行输出。
